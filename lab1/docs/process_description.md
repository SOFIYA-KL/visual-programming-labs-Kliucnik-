# Процесс: Бронирование номера в отеле

## Участники (роли)
- **Гость** — клиент, желающий забронировать номер
- **Сайт отеля** — система онлайн-бронирования
- **Система PMS** — внутренняя система управления номерным фондом
- **Платёжный шлюз** — внешний сервис оплаты
- **Администратор стойки** — сотрудник отеля

## Шаги процесса

1. Гость заходит на сайт отеля и выбирает даты заезда и выезда.
2. Система показывает список доступных номеров с ценами.
3. Гость выбирает подходящий номер и категорию.
4. **Ветвление 1:** если номер доступен на выбранные даты — процесс продолжается; иначе — система предлагает альтернативные даты или номера.
5. Гость заполняет контактные данные и данные гостей.
6. **Ветвление 2:** если применён промокод — система пересчитывает стоимость со скидкой; иначе — цена остаётся базовой.
7. **Параллельно:** система резервирует номер в PMS, а платёжный шлюз запрашивает авторизацию карты.
8. **Ветвление 3:** если оплата прошла успешно — бронь подтверждается; иначе — номер освобождается, гость получает уведомление об ошибке.
9. Система отправляет гостю письмо с подтверждением и номером брони.
10. Гость прибывает в отель, администратор находит бронь по номеру или фамилии.
11. Администратор регистрирует гостя и выдаёт ключ от номера.
12. Гость заселяется — процесс завершён.
