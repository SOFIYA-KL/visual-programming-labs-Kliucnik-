# Отчёт по лабораторной работе №1

## Описание процесса

Выбран процесс **бронирования номера в отеле**. Участники процесса: гость, сайт отеля, система PMS (Property Management System) и платёжный шлюз. Процесс включает проверку доступности номера, применение промокода со скидкой, параллельные операции резервирования и оплаты, а также ветвление по результату оплаты — успешное подтверждение брони или уведомление об ошибке.

## Сравнение diff для текстового и бинарного форматов

В ходе работы был добавлен новый элемент в BPMN-диаграмму и сделан коммит `Update BPMN: add minor element`. При просмотре diff через GitHub видно разницу:

- **Файл `process.bpmn` (текстовый XML)** — Git показал конкретные добавленные и удалённые строки. Видно, какие именно элементы схемы добавились.
- **Файл `process-bpmn.png` (бинарный)** — Git показал только сообщение «Binary file not shown» без деталей.

Это наглядно демонстрирует, что текстовые форматы удобнее для версионирования: можно отследить каждое изменение. А бинарные файлы Git не умеет сравнивать построчно.
