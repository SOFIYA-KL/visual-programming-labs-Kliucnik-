### 2.3. Sequence Diagram

```mermaid
sequenceDiagram
    participant G as Гость
    participant W as Сайт отеля
    participant P as Система PMS
    participant Pay as Платёжный шлюз

    G->>W: Выбирает даты и номер
    W->>P: Запрос доступности
    P-->>W: Номер доступен
    W->>G: Показать стоимость
    G->>W: Подтвердить и ввести данные

    par Параллельно
        W->>P: Зарезервировать номер
        W->>Pay: Авторизовать оплату
    end

    alt Оплата успешна
        Pay-->>W: Платёж подтверждён
        P-->>W: Бронь создана
        W->>G: Письмо с подтверждением
    else Оплата отклонена
        Pay-->>W: Ошибка оплаты
        W->>P: Освободить номер
        W->>G: Уведомление об ошибке
    end
```

- **Исходник:** [docs/sequence.md](docs/sequence.md)

## 3. Сравнение текстовых и бинарных форматов (git diff)

| Формат | Тип | Как Git показывает изменения |
|---|---|---|
| `.bpmn` (XML) | текстовый | Построчно: видно добавленные/удалённые строки |
| `.drawio` (XML) | текстовый | Построчно: видно новую фигуру и связи |
| `.md` (Mermaid) | текстовый | Построчно: видно каждое добавленное сообщение |
| `.png` | бинарный | Только `Binary files ... differ` — без деталей |

**Вывод:** текстовые исходники удобно версионировать — изменения читаемы. Бинарные PNG для сравнения версий почти бесполезны.
