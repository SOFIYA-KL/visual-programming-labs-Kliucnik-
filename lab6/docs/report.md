# Лабораторная работа №6. Kodular

## 1. Описание базового приложения
В ходе работы было создано мобильное приложение «Приветствие» на платформе Kodular. Приложение запрашивает имя пользователя и выводит персонализированное приветствие.

**Компоненты (Screen1):**
- `Label1` — заголовок «Введите имя».
- `Text_Box1` — поле ввода (Hint = «Ваше имя»).
- `Button1` — кнопка «Поздороваться».
- `Label2` — для вывода результата.
- `Label3` — с фамилией студента на английском (`Kliucnik`).

**Логика (Blocks):**
- Блок `when Button1.Click do`.
- Два условия `if then`:
  1. Если `TextBox1.Text = ""` (пусто), выводится «Введите имя!».
  2. Если `TextBox1.Text ≠ ""` (не пусто), используется блок `join` для склейки строки «Привет, », самого имени и «!».
